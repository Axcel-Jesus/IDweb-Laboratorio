Estándar web: PNG

¿Qué es PNG?

PNG significa Portable Network Graphics. Es un formato de imagen abierto utilizado en la web para guardar imágenes con buena calidad y sin perder información.

Características

PNG utiliza compresión sin pérdida y permite transparencias mediante el canal alfa. Es especialmente útil para logotipos, iconos, capturas de pantalla e imágenes que necesitan bordes definidos.

Uso en la web

Los navegadores modernos son compatibles con PNG, por eso puede insertarse en una página HTML usando la etiqueta img. En este sitio se utiliza para mostrar varias imágenes.
